# 社区介绍

## 服务器信息

版本：Unknow - 26.2

- Acovia 服务器启用正版验证。

## 一些特殊玩法

柏茯灵使用数据包为服务器编写了一些特殊玩法，如下：

### 资源开采处：资源维度

为了服务器的长久发展，柏茯灵不提倡在主世界获取一些不可再生资源，因为这会严重破坏服务器的地形，久而久之服务器的地形会变得支离破碎，所以柏茯灵在内层服务器设立了资源维度来供玩家随意开采。

进入方式如下：

主世界坐标 (129 70 132) 处可右键告示牌传送至资源维度。

如果告示牌不在，可以激活命令方块重新生成。

### Eroven

手持 Eroven 的玩家受到致命伤害时，会立刻被拉回到安全区域，作为死亡不掉落的替代方案。

合成方法如下：
|-|-|
|---|---|
| 花 | 钻石 |
| - | - |

### 回溯卷轴

右键使用此卷轴，可以回到主城。

合成方法如下：

|-|-|
|---|---|
| 纸 | 末影珍珠 |
| - | - |

### 资源管理局

资源管理局位于 (184 71 128)，可从此处购买木材、石材等材料。

### 附魔商店

附魔商店位于 (319 63 71)，可从此购买通用附魔书。

## 加入服务器

你需要安装一个兼容的 minecraft 版本来进入服务器，同时不限制模组加载器。

你需要一个 Java 版的正版账号。

地址：

```txt
acovia.net
```

## 服务器规则

服务器内规则条款：

- 禁止在主世界挖掘资源、破坏地形、破坏建筑，服务器有设立独立的资源维度，采集资源请前往资源维度，请查看 [资源开采处：资源维度](#资源开采处资源维度)

- 小型生电机器请在资源维度制造，若生电机器有建造地狱门需求，可以在主世界 (1024, 1024) ~ (1536, 1536) 处建造。

- 允许在本服务器内宣传其他服务器，但禁止吹捧，拉踩。

- 加入本服务器即表示您已阅读并同意条款并遵守服务器规则。
